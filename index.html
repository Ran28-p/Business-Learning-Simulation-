      Sinkron cloud

      Masuk untuk menyimpan progres di cloud.

      Data di perangkat ini berbeda dengan data akun Anda di cloud. Pilih cara menggabungkan; tidak ada yang diubah sebelum Anda memilih.

        Disinkronkan: Accounting, Excel, SQL & Power Query, dan Game Hub (bonus XP & lencana). Simulator SPT punya sinkron cloud sendiri. Reset progres di satu perangkat ikut berlaku di perangkat lain.

        Progres tersimpan di browser perangkat ini. Gunakan Ekspor Progres untuk cadangan atau pindah perangkat. File ekspor memuat data modul apa adanya (termasuk nama/email bila Anda pernah login di SPT), jadi simpan dan bagikan dengan hati-hati.
