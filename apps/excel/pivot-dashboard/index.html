Dataset Penjualan Fiktif

Dataset ini dibuat otomatis (180+ baris transaksi, Januari–Juni 2025) supaya kamu bisa langsung praktik tanpa perlu data sungguhan. Struktur kolomnya sengaja dibuat seperti data mentah khas sebelum diringkas dengan Pivot Table.

Susun Pivot Table-mu

Pilih field untuk Baris, Kolom, dan Nilai — persis seperti panel "PivotTable Fields" di Excel asli.

  1. Buka Tab 1: Data Sumber untuk membaca kolom dan contoh transaksi mentah.
  2. Susun field di bawah, lalu klik Buat / Perbarui Pivot.
  3. Bandingkan ringkasan dengan data mentah dan jawab tantangan di bawah hasil Pivot.
