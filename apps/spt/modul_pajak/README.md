# Modul Pajak Lengkap

Halaman ini berisi ringkasan singkat tiap jenis pajak yang diminta dan kuis latihan singkat per topik.

Cara pakai:
- Buka `index.html` modul dari SIM-SPT atau langsung `modul_pajak/index.html`.
- Pilih topik di kiri, baca ringkasan, lalu klik "Mulai Kuis".
- Isi jawaban lalu tekan "Kirim Jawaban" untuk melihat skor.
